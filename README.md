# 🏢 Enterprise Retail Intelligence Platform

## Demand Forecasting, Inventory Optimization and Decision Support System

An end-to-end retail intelligence platform developed using the **M5 Forecasting Competition Dataset**.

The system combines **Machine Learning-based Demand Forecasting, Inventory Optimization, Explainable AI, and Streamlit Deployment** to support retail business decision-making.

---

## 🎯 Project Objective

The main objective of this project is to develop an intelligent retail decision-support system that can:

- 📈 Forecast product demand
- 📦 Optimize inventory levels
- 🚨 Identify reorder requirements
- 🔍 Explain important factors behind predictions
- 📊 Analyze actual vs predicted sales
- 💡 Support data-driven retail decisions

---

## 📊 Dataset

This project uses the **M5 Forecasting Competition Dataset**.

The dataset contains hierarchical retail sales information including:

- Products
- Departments
- Categories
- Stores
- States
- Daily sales
- Calendar information
- Events and holidays
- Product selling prices

### Dataset Files

The application uses the following M5 dataset files:

sales_train_validation.csv
calendar.csv
sell_prices.csv
